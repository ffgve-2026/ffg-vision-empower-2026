3. API AUTHENTICATION
---------------------
The APIs require an authenticated Frappe user.
Use this header for API calls:
Authorization: token ${API_KEY}:${API_SECRET}
Alternatively, you can authenticate via cookies by sending a POST to `/api/method/login` with `usr` and `pwd`.

4. ENDPOINT SUMMARY & USAGE
---------------------------
All 4 Master Data entities support the exact same CRUD lifecycle.

ITEM (Naming series: VE-ITM-.####)
----------------------------------
GET    /api/method/vision_empower.api.item.list_items
GET    /api/method/vision_empower.api.item.get_item?name=VE-ITM-0001
POST   /api/method/vision_empower.api.item.create_item  (Body: {"data": "{\"active\": 1}"})
POST   /api/method/vision_empower.api.item.update_item  (Body: {"name": "VE-ITM-0001", "data": "{\"active\": 1}"})
POST   /api/method/vision_empower.api.item.discontinue_item (Body: {"name": "VE-ITM-0001"}) -> sets active=0

5. IMPORTANT NOTES
------------------
- "Read" endpoints (list & get) check `read` permissions on the DocType (allowed for 'All').
- "Write" endpoints (create, update, delete) check `write` / `delete` permissions (restricted to 'System Manager').
- Note: POST body data parameter MUST be a stringified JSON (e.g. `{"data": "{\"key\": \"value\"}"}`).

BULK CSV IMPORT (Generic)
-------------------------
POST   /api/method/vision_empower.vision_empower.api.bulk_import_csv
       Parameters:
       - doctype: The name of the master data table (e.g. "Item", "School", "Vendor")
       - file: (multipart/form-data) The CSV file to upload. The CSV headers must match the DocType fieldnames.
       
       Example using curl:
       curl -X POST http://127.0.0.1:8000/api/method/vision_empower.vision_empower.api.bulk_import_csv \
            -H "Authorization: token ${API_KEY}:${API_SECRET}" \
            -F "doctype=Item" \
            -F "file=@/path/to/items.csv"
