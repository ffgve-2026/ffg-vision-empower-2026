3. API AUTHENTICATION
---------------------
The APIs require an authenticated Frappe user.
Use this header for API calls:
Authorization: token ${API_KEY}:${API_SECRET}
Alternatively, you can authenticate via cookies by sending a POST to `/api/method/login` with `usr` and `pwd`.

4. ENDPOINT SUMMARY & USAGE
---------------------------
All 4 Master Data entities support the exact same CRUD lifecycle.

ITEM (Naming series: VE-ITM-.####)
----------------------------------
GET    /api/method/master_data.api.item.list_items
GET    /api/method/master_data.api.item.get_item?name=VE-ITM-0001
POST   /api/method/master_data.api.item.create_item  (Body: {"data": "{\"active\": 1}"})
POST   /api/method/master_data.api.item.update_item  (Body: {"name": "VE-ITM-0001", "data": "{\"active\": 1}"})
POST   /api/method/master_data.api.item.discontinue_item (Body: {"name": "VE-ITM-0001"}) -> sets active=0

VENDOR (Naming series: VE-VEN-.####)
------------------------------------
GET    /api/method/master_data.api.vendor.list_vendors
GET    /api/method/master_data.api.vendor.get_vendor?name=VE-VEN-0001
POST   /api/method/master_data.api.vendor.create_vendor (Body: {"data": "{\"vendor_name\": \"Vendor A\"}"})
POST   /api/method/master_data.api.vendor.update_vendor (Body: {"name": "VE-VEN-0001", "data": "{\"phone\": \"1234\"}"})
POST   /api/method/master_data.api.vendor.deactivate_vendor (Body: {"name": "VE-VEN-0001"}) -> sets active=0

SCHOOL (Naming series: VE-SCH-.####)
------------------------------------
GET    /api/method/master_data.api.school.list_schools
GET    /api/method/master_data.api.school.get_school?name=VE-SCH-0001
POST   /api/method/master_data.api.school.create_school (Body: {"data": "{\"school_code\": \"SCH1\", \"school_name\": \"Test\"}"})
POST   /api/method/master_data.api.school.update_school (Body: {"name": "VE-SCH-0001", "data": "{\"address\": \"XYZ\"}"})
POST   /api/method/master_data.api.school.delete_school (Body: {"name": "VE-SCH-0001"}) -> hard delete

5. IMPORTANT NOTES
------------------
- "Read" endpoints (list & get) check `read` permissions on the DocType (allowed for 'All').
- "Write" endpoints (create, update, delete) check `write` / `delete` permissions (restricted to 'System Manager').
- Note: POST body data parameter MUST be a stringified JSON (e.g. `{"data": "{\"key\": \"value\"}"}`).
